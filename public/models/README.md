# Local face detector model

`blaze_face_short_range.tflite` is the official MediaPipe BlazeFace short-range
float16 model (version 1), selected for selfie-like images. It is served by the
Sparkle Insure app and runs locally in the member's browser.

Source: https://storage.googleapis.com/mediapipe-models/face_detector/blaze_face_short_range/float16/1/blaze_face_short_range.tflite
